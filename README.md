# Transient Study Media Library

This public GitHub Pages repository contains the study media plus the processed alternatives and earlier test/calibration outputs. Raw recordings are intentionally excluded.

## Current survey set

- 42 original 250 ms training clips: 6 instruments × 7 pitches.
- 168 experimental clips: 6 instruments × 7 pitches × 4 conditions (SN/STN at 25/50 ms).
- 6 instrument images used in the current survey.

These are grouped under `audio/training/`, `audio/experimental/`, and `images/`. [media_links.csv](media_links.csv) is the concise link list for this survey set.

## Full processed library

`library/processed/` mirrors every audio and image file in the processed stimulus folder, including the current training/experimental stimuli and archived crop checks, onset reviews, duration pilots, and SiTraNo preparation outputs. `library/images/` contains all nine instrument pictures from the project assets folder. This includes options beyond the current six-instrument survey design.

[all_media_links.csv](all_media_links.csv) lists every hosted audio and image file, its collection, any recognizable instrument/pitch/condition/duration, and its direct public URL. The library contains 2,131 media files (2,122 audio files and 9 images), about 420 MiB. Raw recordings and non-media project documents are not included.

## Playback demo compatibility

The `test/` folder archives the successful short-duration playback demo. Two root-level audio paths (`audio/piano-C4-SN-25ms.wav` and `audio/piano-C4-SN-50ms.wav`) remain as compatibility URLs for the disposable Qualtrics test already imported; the same clips also appear in the full library.

All hosted files are public. The survey stores participant responses in Qualtrics; this site only serves media.
