# Transient Study Media Library

This public GitHub Pages site hosts only the media selected for the current survey design:

- 42 original 250 ms training clips: 6 instruments × 7 pitches.
- 168 experimental clips: 6 instruments × 7 pitches × 4 conditions (SN/STN at 25/50 ms).
- 6 instrument images used during training and practice feedback.

The media are grouped under `audio/training/`, `audio/experimental/`, and `images/`. [media_links.csv](media_links.csv) maps each asset to its filename, instrument, pitch, condition, and public URL. [index.html](index.html) is a quick entry point.

The `test/` folder archives the successful short-duration playback demo and its two copies of the test clips. Two root-level audio paths (`audio/piano-C4-SN-25ms.wav` and `audio/piano-C4-SN-50ms.wav`) remain as compatibility URLs for the disposable Qualtrics test already imported. The same clips also appear in the canonical experimental folder.

All hosted files are publicly reachable. The survey stores participant responses in Qualtrics; this site only serves media.
