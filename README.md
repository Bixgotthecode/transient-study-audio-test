# Public audio test site

This minimal GitHub Pages site serves two disposable piano C4 SN clips to verify public, filename-based audio URLs in Qualtrics. It contains no response collection or backend.

The media paths are stable:

- `audio/piano-C4-SN-25ms.wav`
- `audio/piano-C4-SN-50ms.wav`

Once deployed at `https://bixgotthecode.github.io/transient-study-audio-test/`, those paths form the direct URLs used by the Advanced TXT test.
